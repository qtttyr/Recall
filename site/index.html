How to run without Apple Developer ID (Gatekeeper Guide)

Recall is an independent, community open-source project. Because we don't pay Apple's $99/year developer tax, macOS Gatekeeper may show a warning on first launch. Here is how any MacBook user can run it cleanly:

1
Method A: The 1-Line Install (Recommended)
Run the curl script in Terminal. It downloads the release, moves it to /Applications, and clears the download quarantine flag automatically. Zero warnings!
2
Method B: Direct DMG (macOS Sequoia 15+)
Drag Recall to Applications. Double-click it once. Dismiss the prompt, open System Settings → Privacy & Security, scroll down to Security, and click "Open Anyway".
3
Method C: Single Terminal Command
If you already downloaded the DMG, open Terminal and run:
xattr -cr /Applications/Recall.app
This strips the quarantine attribute instantly.
